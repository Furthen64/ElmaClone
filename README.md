# ElmaClone

2d dirtbike game with simple graphics in pygame, inspired by elastomania / across.

## First playable version (v1)

This repository now includes a first playable prototype:

- rolling terrain track
- bike movement, jump, and in-air tilt controls
- crash detection and restart
- finish line with win state

## Run

```bash
python -m pip install -r requirements.txt
python game.py
```

## Controls

- Left / Right: move
- Up / Down: tilt bike
- Space: jump
- R: restart
